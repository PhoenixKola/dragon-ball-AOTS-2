# Active art reference register

This register maps the active runtime art to its reviewed source and integration path. `public/assets/reviewed/` is the runtime source of truth; source sheets are development-only and excluded from the Windows player archive.

| Art group | Runtime registry | Reviewed runtime files | Development source / pipeline |
|---|---|---|---|
| Battle actors and still poses | `src/data/spriteManifest.generated.ts` | `public/assets/reviewed/actors/<actor>_<pose>.png` | Original reviewed asset pack; manifests generated by `tools/gen_sprite_manifest.py` |
| Goku Kaioken and Super Saiyan | `src/data/powerupSprites.generated.ts` | `public/assets/reviewed/actors/pw_goku_*.png` | Existing form sheets and `tools/slice_goku_forms.py`; see `docs/GOKU_FORMS.md` |
| Core-party melee | `src/data/battleAnimationFrames.ts` | Four `*_attack_frame_01..04.png` files each for Goku, Gohan, Krillin, Vegeta, Piccolo | `art-sources/production/<hero>/base_punch_source.png`; `tools/integrate_party_punches.py` |
| Frieza2, Frieza5 and Cooler melee | `src/data/battleAnimationFrames.ts` | Four registered `*_attack_frame_01..04.png` files per actor | Native generated contact sheet and metadata in `art-sources/production/<actor>/`; `tools/integrate_strike_contact.py` |
| Battle/title backgrounds | `src/engine/scenes/stageBackgrounds.ts`, `TitleScene.ts` | `public/assets/backgrounds/{title,plain,water,village,ship,cave,ruin,final,frozen}_namek.png` | Native generated originals and metadata in `art-sources/production/backgrounds/`; `tools/integrate_backgrounds.py` |
| Battle beams, impact and aura VFX | `src/data/artManifest.generated.ts`, `src/data/auraRise.generated.ts` | `public/assets/reviewed/vfx/`, `public/assets/reviewed/vfx/aura_rise/` | Reviewed local art pack; VFX mappings in `src/engine/animation/vfxSprites.ts` |
| World tiles, objects and field characters | `src/engine/world/worldAssets.ts`, `src/engine/world/overworld.ts` | `public/assets/world/`, `public/assets/reviewed/overworld/` | Existing reviewed beta assets; this experience pass did not replace the world tiles/NPC atlas |
| UI panels and controls | `src/components/`, `src/app/styles.css` | `public/assets/reviewed/ui/` | Existing reviewed panel, cursor, and icon set; CSS and React own layout and states |

Exact pose/form animation coverage and fallback status lives in [ANIMATION_COVERAGE.csv](ANIMATION_COVERAGE.csv). Active-file existence, alpha, canvas/anchors, frame uniqueness, and backgrounds are checked by `npm run audit:runtime`. The audit is intentionally scoped and is not a full unused-file/perceptual-duplicate scan.
