# Asset manifest

Runtime art lives only under `public/assets/` (reviewed/actors, reviewed/overworld, reviewed/icons, reviewed/vfx, reviewed/ui, portraits, world). Every file is new AI-generated pixel art from the supplied sheets (see `docs/V4_INTEGRATION_REPORT.md` for exactly which sheet fed which folder and the tools that regenerate them). Raw sheets and replaced files are kept outside the runtime under `art-sources/`.
