# Audio cue sheet

The review build retains the project's original local WebAudio score and synthesized SFX. Music cue definitions are in `src/engine/audio/music.ts` (title, Namek regions, Ginyu, regular/boss/Frieza/final battles, SSJ, ending, Cooler, victory, defeat). Effects and music/UI/SFX volume buses are in `src/engine/audio/audio.ts`; settings persist locally. No soundtrack file, external license, API, or runtime network request was added.

Audio was inspected in source, not listened to by ear in this environment. Mixing, emotional pacing, and actual Windows speaker/headphone behavior remain unverified. The requested original soundtrack improvement has not been completed.
